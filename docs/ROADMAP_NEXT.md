# V1 → Commercial Pilot Roadmap

## Sprint A — Production identity/data
- Supabase project
- Auth SSR
- RLS tests
- workspace onboarding
- member invitations and roles
- data adapter replacement

## Sprint B — WhatsApp channel
- Meta webhook
- contact/thread matching
- inbound persistence
- outbound send
- delivery/read status
- retries and idempotency

## Sprint C — AI & automation reliability
- Responses API adapter
- prompt versions
- human-in-the-loop drafts
- automation scheduler/worker
- audit log
- usage/cost meter

## Sprint D — Monetization/operations
- billing/entitlements
- onboarding checklist
- CSV contact import
- support/admin console
- error monitoring
- privacy/export/delete flows

## Sprint E — 10-client pilot
- onboarding 10 companies from one vertical
- weekly user interviews
- measure: activation, follow-up completion, recovered opportunities, time-to-value
- no new major modules until retention signal is clear
